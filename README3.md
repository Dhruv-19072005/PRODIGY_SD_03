## 📋 Task Overview

> **PRODIGY_SD_03** — Software Development Internship

A program that allows users to store and manage contact information. Users can add a new contact with name, phone number, and email address, view their contact list, edit existing contacts, and delete contacts. Contacts are stored persistently in a file, so data is not lost when the program closes.

## ✨ Features

- ➕ Add a new contact (name, phone, email)
- 📋 View all saved contacts
- ✏️ Edit an existing contact
- 🗑️ Delete a contact
- 💾 Persistent storage using a JSON file
- ✅ Input validation for menu choices

## 🛠️ Technologies Used

- **Python 3**
- **JSON** (for file-based persistent storage)
